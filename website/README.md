# LidPilot website

This directory is ready to serve as a static GitHub Pages artifact. It has no dependencies, external fonts, scripts, trackers, cookies, or network requests beyond its own HTML/CSS.

The illustrated menu is labeled as an illustration. The site intentionally has no download button or invented repository URL: public release remains gated. Before publication, add the actual signed-release/source links and verified screenshots, confirm every claim against `docs/HARDWARE_VALIDATION.md`, and place the signed appcast and release notes in the configured update path. Never edit metadata after signing it.

Local preview: `python3 -m http.server 8766 --directory website`. Publishing is a separate, explicitly authorized action.
